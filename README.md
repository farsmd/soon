# مدیریت محتوای ساده PHP + SQLite — نسخه ۲

یک وب‌اپ ساده با PHP که همه فایل‌هایش در **یک فولدر** کنار هم قرار دارند و دیتابیسش SQLite است. صفحه اصلی از چند قالب PHP تشکیل می‌شود که از پنل مدیریت، به هر ترتیبی می‌توانید آن‌ها را بچینید؛ یا می‌توانید فقط یک قالب تک‌صفحه فعال کنید. نسخه ۲ چندصفحه‌ای شدن، محتوای واقعی برای هر بخش با آپلود عکس، اسلایدر واقعی، تم روشن/تیره، فرم تماس و ابزار بکاپ را اضافه می‌کند.

## چه چیزهایی در نسخه ۲ تازه است؟

- **چندصفحه‌ای:** از پنل «صفحه‌ها» صفحه جدا بسازید (عنوان، نامک، محتوا، عنوان و توضیح سئو، فعال/غیرفعال، نمایش در منو). آدرس هر صفحه `page.php?slug=نامک` است. منوی سایت خودکار از همین صفحه‌ها ساخته می‌شود و لینک «خانه» همیشه اول آن است.
- **محتوای واقعی هر بخش:** هر بخش تیتر، متن (HTML ساده)، عکس، آدرس لینک و متن دکمه دارد. قالب‌ها (هدر/اسلایدر/ویژگی‌ها/محتوا/فوتر/تک‌صفحه) از همین محتوا استفاده می‌کنند؛ اگر فیلدی خالی باشد، محتوای پیش‌فرض نشان داده می‌شود تا سایت تازه هم کامل دیده شود.
- **آپلود عکس:** برای هر بخش عکس آپلود کنید (jpg/png/webp/gif، حداکثر ۳ مگابایت). عکس‌ها در فولدر `uploads` کنار بقیه فایل‌ها می‌نشینند و اجرای PHP در آن فولدر بسته است.
- **اسلایدر واقعی:** اسلایدر از عکس، تیتر، متن و دکمه همان بخش استفاده می‌کند؛ بدون عکس، پس‌زمینه گرادیانی نمایش داده می‌شود.
- **تم روشن/تیره:** دکمه تغییر تم در هدر (ذخیره در مرورگر کاربر با localStorage).
- **فرم تماس:** یک بخش با قالب `template_contact.php` بسازید. پیام‌ها در دیتابیس ذخیره و در پنل «پیام‌های تماس» دیده و حذف می‌شوند. فرم CSRF، فیلد مخفی ضدربات و بررسی زمان ارسال دارد.
- **سئو:** برای هر صفحه عنوان و توضیح سئوی جدا، و برای صفحه اصلی هم از «تنظیمات» عنوان و توضیح سئو تعیین کنید.
- **بکاپ و بازیابی:** از «ابزار و بکاپ» بکاپ دیتابیس دانلود کنید یا بکاپ قبلی را بازیابی کنید. قبل از بازیابی، از دیتابیس فعلی نسخه امن (`database-backup-before-restore.sqlite`) نگه داشته می‌شود و بعد از بازیابی باید دوباره وارد شوید.

## فایل‌ها

| فایل | توضیح |
|---|---|
| `index.php` | صفحه اصلی — بخش‌های فعال را به ترتیب و با محتوای خودشان لود می‌کند |
| `page.php` | نمایش صفحه‌های جدا با آدرس `page.php?slug=...` |
| `admin.php` | پنل مدیریت (پسورددار) |
| `config.php` | اتصال SQLite، مهاجرت خودکار دیتابیس، ساخت جدول‌ها و توابع کمکی |
| `database.sqlite` | دیتابیس — در اولین اجرا خودکار ساخته می‌شود (در بسته زیپ نیست) |
| `template_header.php` | قالب هدر (با منوی خودکار و سئوی صفحه اصلی) |
| `template_slider.php` | قالب اسلایدر (عکس/تیتر/متن/دکمه بخش) |
| `template_features.php` | قالب بخش ویژگی‌ها |
| `template_content.php` | قالب بخش محتوای اصلی |
| `template_contact.php` | قالب فرم تماس (به‌عنوان یک بخش به صفحه اصلی اضافه می‌شود) |
| `template_footer.php` | قالب فوتر |
| `template_single.php` | قالب تک‌صفحه کامل (مستقل) |
| `style.css` | استایل صفحه اصلی با تم روشن/تیره |
| `uploads/` | عکس‌های آپلودی بخش‌ها (دارای `.htaccess` برای بستن اجرای PHP) |
| `.htaccess` | محافظت از فایل دیتابیس و `config.php` در آپاچی |

## نیازمندی‌ها

- PHP نسخه 7.4 یا بالاتر (پیشنهاد: PHP 8)
- افزونه‌های `pdo` و `pdo_sqlite` و `fileinfo` (معمولاً همراه PHP هستند)

## نصب تازه

### روی کامپیوتر خودتان (سرور داخلی PHP)

```bash
cd simple-php-cms-v2
php -S localhost:8000
```

بعد در مرورگر باز کنید:

- سایت: http://localhost:8000
- مدیریت: http://localhost:8000/admin.php

در **اولین ورود به مدیریت**، از شما خواسته می‌شود یک پسورد بسازید (حداقل ۸ کاراکتر). دفعات بعد با همان پسورد وارد می‌شوید. پسورد به صورت هش‌شده (`password_hash`) در دیتابیس ذخیره می‌شود و از قسمت «تنظیمات و پسورد» قابل تغییر است.

### روی هاست

کل فولدر را روی هاست آپلود کنید. مطمئن شوید فولدر (و فولدر `uploads` داخل آن) برای PHP قابل نوشتن است تا فایل `database.sqlite` و عکس‌ها ساخته شوند. روی آپاچی، فایل `.htaccess` همراه پروژه از دسترسی مستقیم به دیتابیس و `config.php` جلوگیری می‌کند. روی Nginx باید همین دو فایل را در کانفیگ سرور ببندید:

```nginx
location ~ \.(sqlite|sqlite3|db)$ { deny all; }
location = /config.php { deny all; }
location ^~ /uploads/ { location ~ \.php$ { deny all; } }
```

## ارتقا از نسخه ۱ (مهم — سایت زنده)

اگر نسخه ۱ روی هاست شما در حال کار است و دیتابیسش (`database.sqlite`) پسورد و تنظیمات شما را دارد:

1. اول از پنل نسخه ۱ یا از فایل‌منیجر هاست، از فایل `database.sqlite` یک کپی پشتیبان نگه دارید.
2. فایل‌های نسخه ۲ را روی همان فولدر قبلی آپلود کنید (روی فایل‌های هم‌نام بنویسید). فایل تازه‌ی `page.php` و `template_contact.php` و فولدر `uploads` هم اضافه می‌شوند.
3. **فایل `database.sqlite` را پاک نکنید و رویش چیزی ننویسید.** در بسته زیپ نسخه ۲ اصلاً فایل دیتابیس نیست.
4. یک بار سایت یا پنل مدیریت را باز کنید. در همان اولین اجرا، دیتابیس به‌صورت خودکار و درجا ارتقا پیدا می‌کند: جدول‌های تازه ساخته و ستون‌های تازه به بخش‌ها اضافه می‌شوند؛ پسورد مدیریت، تنظیمات و بخش‌های قبلی شما دست‌نخورده می‌مانند.
5. وارد پنل شوید (با همان پسورد قبلی) و بخش «صفحه‌ها»، محتوای بخش‌ها و «ابزار و بکاپ» را بررسی کنید.

## پنل مدیریت چه کارهایی می‌کند؟

- **بخش‌های صفحه اصلی:** افزودن، ویرایش (تیتر، متن، عکس، لینک و دکمه)، حذف، فعال/غیرفعال کردن و جابه‌جایی (بالا/پایین) بخش‌ها. `index.php` دقیقاً به همین ترتیب قالب‌ها را لود می‌کند.
- **صفحه‌ها:** ساخت و ویرایش صفحه‌های جدا با نامک، محتوای HTML ساده، تنظیمات سئو و گزینه نمایش در منو.
- **قالب‌ها:** لیست فایل‌های `template_*.php`، ساخت قالب جدید، ویرایش کد قالب و حذف قالب بلااستفاده.
- **پیام‌های تماس:** مشاهده و حذف پیام‌های فرم تماس.
- **ابزار و بکاپ:** دانلود بکاپ دیتابیس و بازیابی بکاپ (با نگه‌داشتن نسخه امن از دیتابیس فعلی).
- **تنظیمات و پسورد:** تغییر عنوان، توضیح و سئوی صفحه اصلی و تغییر پسورد مدیریت.

## قالب‌ها و کدهای تمپلیت

قالب‌ها فایل‌های PHP معمولی هستند. داخل هر قالب هم می‌توانید کد PHP بنویسید و هم از پلیس‌هولدر استفاده کنید:

| پلیس‌هولدر | جایگزین می‌شود با |
|---|---|
| `{{site_title}}` | عنوان سایت |
| `{{site_description}}` | توضیح سایت |
| `{{seo_title}}` | عنوان سئوی صفحه اصلی (یا عنوان سایت) |
| `{{seo_description}}` | توضیح سئوی صفحه اصلی (یا توضیح سایت) |
| `{{menu}}` | منوی خودکار سایت (خانه + صفحه‌های دارای نمایش در منو + دکمه تغییر تم) |
| `{{current_year}}` | سال جاری |

داخل کد PHP قالب هم این متغیرها در دسترس‌اند: `$site_title` و `$site_description` و آرایه `$settings` و `$section` (تیتر، متن، عکس و لینک بخش جاری) و تابع `e()` برای خروجی امن؛ مثلاً:

```php
<h2><?= e($section['heading'] ?? '') ?></h2>
```

توجه: فیلد «متن بخش» و «محتوای صفحه» با HTML ساده ذخیره و همان‌طور نمایش داده می‌شوند؛ این‌ها را فقط مدیر سایت می‌نویسد. تیترها و عنوان‌ها همیشه به‌صورت امن (escape شده) خروجی داده می‌شوند.

### قالب جدید بسازید

از پنل مدیریت، بخش «قالب‌ها»، یک نام (فقط حروف انگلیسی، عدد و آندرلاین) بدهید تا فایل `template_<نام>.php` ساخته شود. بعد یک «بخش» با آن قالب بسازید تا در صفحه اصلی نمایش داده شود.

### قالب تک‌صفحه

فایل `template_single.php` یک صفحه کامل و مستقل است. برای استفاده از آن: در پنل مدیریت همه بخش‌ها را غیرفعال کنید و فقط یک بخش با قالب `template_single.php` فعال بگذارید. در این حالت `index.php` همان یک قالب را به صورت کامل خروجی می‌دهد.

### فرم تماس

در پنل «بخش‌های صفحه اصلی» یک بخش تازه با قالب `template_contact.php` بسازید و ترتیبش را هرجا خواستید بگذارید (مثلاً قبل از فوتر). تیتر و متن بالای فرم از محتوای همان بخش می‌آید. پیام‌ها در پنل «پیام‌های تماس» قابل مشاهده‌اند.

## نکته امنیتی

ویرایش کد قالب از پنل مدیریت یعنی اجرای کد PHP روی سایت؛ این قابلیت فقط برای مدیر سایت است. پسورد قوی انتخاب کنید و آدرس پنل را در اختیار دیگران نگذارید. عکس‌های آپلودی در فولدر `uploads` نگه داشته می‌شوند و اجرای فایل PHP در آن فولدر با `.htaccess` بسته است، ولی روی Nginx باید جدا ببندید (نمونه کانفیگ بالا). این پروژه یک CMS آموزشی و سبک است و برای سایت‌های حساس به امنیت بالا طراحی نشده است.
