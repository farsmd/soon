# مدیریت محتوای ساده PHP + SQLite

یک وب‌اپ ساده با PHP که همه فایل‌هایش در **یک فولدر** کنار هم قرار دارند و دیتابیسش SQLite است. صفحه اصلی از چند قالب PHP تشکیل می‌شود که از پنل مدیریت، به هر ترتیبی می‌توانید آن‌ها را بچینید؛ یا می‌توانید فقط یک قالب تک‌صفحه فعال کنید.

## فایل‌ها

| فایل | توضیح |
|---|---|
| `index.php` | صفحه اصلی — بخش‌های فعال را به ترتیب لود می‌کند |
| `admin.php` | پنل مدیریت (پسورددار) |
| `config.php` | اتصال SQLite، ساخت خودکار جدول‌ها و توابع کمکی |
| `database.sqlite` | دیتابیس — در اولین اجرا خودکار ساخته می‌شود (در بسته زیپ نیست) |
| `template_header.php` | قالب هدر |
| `template_slider.php` | قالب اسلایدر اصلی |
| `template_features.php` | قالب بخش ویژگی‌ها |
| `template_content.php` | قالب بخش محتوای اصلی |
| `template_footer.php` | قالب فوتر |
| `template_single.php` | قالب تک‌صفحه کامل (مستقل) |
| `style.css` | استایل صفحه اصلی |
| `.htaccess` | محافظت از فایل دیتابیس و `config.php` در آپاچی |

## نیازمندی‌ها

- PHP نسخه 7.4 یا بالاتر (پیشنهاد: PHP 8)
- افزونه‌های `pdo` و `pdo_sqlite` (معمولاً همراه PHP هستند)

## نصب و اجرا

### روی کامپیوتر خودتان (سرور داخلی PHP)

```bash
cd simple-php-cms
php -S localhost:8000
```

بعد در مرورگر باز کنید:

- سایت: http://localhost:8000
- مدیریت: http://localhost:8000/admin.php

در **اولین ورود به مدیریت**، از شما خواسته می‌شود یک پسورد بسازید (حداقل ۸ کاراکتر). دفعات بعد با همان پسورد وارد می‌شوید. پسورد به صورت هش‌شده (`password_hash`) در دیتابیس ذخیره می‌شود و از قسمت «تنظیمات و پسورد» قابل تغییر است.

### روی هاست

کل فولدر را روی هاست آپلود کنید. مطمئن شوید فولدر برای PHP قابل نوشتن است تا فایل `database.sqlite` ساخته شود. روی آپاچی، فایل `.htaccess` همراه پروژه از دسترسی مستقیم به دیتابیس و `config.php` جلوگیری می‌کند. روی Nginx باید همین دو فایل را در کانفیگ سرور ببندید:

```nginx
location ~ \.(sqlite|sqlite3|db)$ { deny all; }
location = /config.php { deny all; }
```

## پنل مدیریت چه کارهایی می‌کند؟

- **بخش‌های صفحه اصلی:** افزودن، ویرایش، حذف، فعال/غیرفعال کردن و جابه‌جایی (بالا/پایین) بخش‌ها. `index.php` دقیقاً به همین ترتیب قالب‌ها را لود می‌کند.
- **قالب‌ها:** لیست فایل‌های `template_*.php`، ساخت قالب جدید، ویرایش کد قالب و حذف قالب بلااستفاده.
- **تنظیمات و پسورد:** تغییر عنوان و توضیح سایت و تغییر پسورد مدیریت.

## قالب‌ها و کدهای تمپلیت

قالب‌ها فایل‌های PHP معمولی هستند. داخل هر قالب هم می‌توانید کد PHP بنویسید و هم از پلیس‌هولدر استفاده کنید:

| پلیس‌هولدر | جایگزین می‌شود با |
|---|---|
| `{{site_title}}` | عنوان سایت |
| `{{site_description}}` | توضیح سایت |
| `{{current_year}}` | سال جاری |

داخل کد PHP قالب هم این متغیرها در دسترس‌اند: `$site_title` و `$site_description` و آرایه `$settings` و تابع `e()` برای خروجی امن؛ مثلاً:

```php
<h1><?= e($site_title) ?></h1>
```

### قالب جدید بسازید

از پنل مدیریت، بخش «قالب‌ها»، یک نام (فقط حروف انگلیسی، عدد و آندرلاین) بدهید تا فایل `template_<نام>.php` ساخته شود. بعد یک «بخش» با آن قالب بسازید تا در صفحه اصلی نمایش داده شود.

### قالب تک‌صفحه

فایل `template_single.php` یک صفحه کامل و مستقل است. برای استفاده از آن: در پنل مدیریت همه بخش‌ها را غیرفعال کنید و فقط یک بخش با قالب `template_single.php` فعال بگذارید. در این حالت `index.php` همان یک قالب را به صورت کامل خروجی می‌دهد.

## نکته امنیتی

ویرایش کد قالب از پنل مدیریت یعنی اجرای کد PHP روی سایت؛ این قابلیت فقط برای مدیر سایت است. پسورد قوی انتخاب کنید و آدرس پنل را در اختیار دیگران نگذارید. این پروژه یک CMS آموزشی و سبک است و برای سایت‌های حساس به امنیت بالا طراحی نشده است.
